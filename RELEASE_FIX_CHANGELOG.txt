SRS Analyzer - Release Fixes / Deployment Readiness

Fixed:
1. Requirement delete popup crash: UserApp now defines uiLanguage, so the custom confirmation popup works instead of throwing ReferenceError.
2. Spring validation messages such as "must not be blank" are normalized to bilingual user-friendly messages.
3. Locking another user no longer overwrites the currently logged-in admin session.
4. Locking a user invalidates that user's existing bearer tokens immediately.
5. Admin page and selected Admin tab persist across F5 using localStorage.
6. Logout/session expiry clears persisted Admin view state.
7. Removed committed DB password and LLM API-key defaults from application.properties; production values must come from environment variables.
8. CORS origin is configurable through APP_CORS_ORIGIN instead of being permanently tied to localhost:5173.
9. Added Render Blueprint, backend Dockerfile, SPA fallback, and deployment guide.

Known verification limitation in this environment:
- The ZIP originally contained Windows-host node_modules. They were removed from this release so deployment installs clean dependencies with npm ci.
- A full frontend build could not be completed in this Linux execution environment because dependency installation is network-dependent. The source changes were statically inspected; run `npm ci && npm run build` on Windows before pushing if desired.
